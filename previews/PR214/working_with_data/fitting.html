Parameter Fitting​#

PlantSimEngine.Evaluation.fit is the shared interface for model-specific calibration. Model packages implement a method whose first argument is the model type and whose second argument is Tables.jl-compatible observations.

The mathematical core of the Beer fit is:

julia
J_to_umol = PlantMeteo.Constants().J_to_umol
incident_ppfd = J_to_umol .* data.Ri_PAR_f
f_abs = data.aPPFD ./ incident_ppfd
k = Statistics.mean(-log1p.(-f_abs) ./ data.LAI)

This snippet shows the inversion only. The implementation in examples/Beer.jl validates every observation and returns (k=k,); do not use the snippet alone as an unchecked fitting method.

The result should be a NamedTuple of fitted parameters.

In this Beer example, Ri_PAR_f is an incident flux per unit ground area and aPPFD is the flux absorbed by the whole canopy, also per unit ground area. LAI is leaf area per unit ground area. Do not use a PPFD expressed per unit leaf area in this inversion. The fit rejects empty data, non-finite or non-positive LAI and incident PAR, and absorbed fractions outside [0, 1).

julia
using PlantSimEngine, PlantMeteo, Dates, DataFrames
using PlantSimEngine.Examples

meteo = Atmosphere(
    T=20.0,
    Wind=1.0,
    P=101.3,
    Rh=0.65,
    Ri_PAR_f=300.0,
    duration=Hour(1),
)

model = CompositeModel(
    Beer(0.6);
    status=(LAI=2.0,),
    id=:plant,
    scale=:Plant,
    environment=meteo,
)

simulation = run!(model)
plant = final_state(simulation, One(scale=:Plant))
data = DataFrame(
    aPPFD=[plant.aPPFD],
    LAI=[plant.LAI],
    Ri_PAR_f=[meteo.Ri_PAR_f[1]],
)

PlantSimEngine.Evaluation.fit(Beer, data)
(k = 0.6,)

This example recovers the parameter used to generate the synthetic observation. Real calibration methods can use any optimizer or uncertainty framework and may return additional diagnostics.

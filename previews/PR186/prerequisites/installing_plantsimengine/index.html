Installing PlantSimEngine

Install Julia from the official download page, create a project environment, and add PlantSimEngine:

using Pkg
Pkg.activate("my_simulation")
Pkg.add("PlantSimEngine")

Most simulations also use PlantMeteo:

Pkg.add("PlantMeteo")

First Simulation

using PlantSimEngine, PlantMeteo, Dates
using PlantSimEngine.Examples

meteo = Atmosphere(
    T=20.0,
    Wind=1.0,
    Rh=0.65,
    Ri_PAR_f=500.0,
    duration=Hour(1),
)

model = CompositeModel(
    Beer(0.5);
    status=(LAI=2.0,),
    id=:leaf,
    scale=:Leaf,
    environment=meteo,
)

simulation = run!(model)
final_state(simulation, One(scale=:Leaf)).aPPFD
1444.3954769232544

Example models are provided by the PlantSimEngine.Examples submodule. They are useful for learning and tests but are not part of the core modeling API.

For local package development, use Pkg.develop(path="..."). Run the package tests with Pkg.test("PlantSimEngine").
